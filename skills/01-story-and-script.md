# 1. Story and script

## The shape (55–60 s)
| Part | Time | Job |
|---|---|---|
| Hook | 0–7 s | The naive version **fails on screen within the first second**. Narrator states the setup and the failure. |
| Fix 1 → problem 2 | ~7–17 s | Solve the failure. The solution is shown mechanically (parts appear, lock in). |
| Fix 2 → problem 3 | ~17–27 s | The previous fix works ("Great, it works!"), then a new problem appears. |
| Fix 3 → problem 4 | ~27–38 s | Same pattern. Often a "hidden systems" beat (power, water, air, heat) shown in cutaway. |
| Fix 4 | ~38–49 s | Introduce it as "One last problem." |
| Reveal | last ~9 s | Pull back to the finished result, one last cutaway glimpse, end on a direct question ("Would you try it?"). |

## The chain rule
Each fix must **cause** or **expose** the next problem. Examples of honest causes:
- Building it taller → now it sways in the wind → bracing → now it's top-heavy.
- Making it lighter → now it gets pushed around → weighting it → now it can't move when it needs to.
- Sealing it → now it needs air/ventilation.
- Digging down → now water seeps in → pump → now it needs power.
Avoid a list of unrelated upgrades; the viewer should feel "oh no, of course".

## Problem-before-narration timing
- Start the visual problem **0.5–2 s before** the narrator names it.
- Use a pause in the narration as the moment the problem appears ("Great. It works." *[pause, problem appears]* "But now…").
- Land key words on their visual moment: the noun of the fix as the part locks in, "switch" as the light turns on.

## Writing the narration
- Second person, present tense: "you put", "you add", "now your…".
- Short sentences, 6–14 words. One idea per sentence.
- About **150–175 words** for 58 s (≈ 180–210 words per minute while speaking, with pauses).
- Structure per beat: *state the problem → state the fix → state the result* (often 2 sentences).
- Last line is a question to the viewer.
- Read it aloud; anything you stumble on, cut.

## Title
"What If You Built a ___ That ___?" or "How a ___ Becomes a ___". The title is the premise; the first frame proves it's in trouble.
